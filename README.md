# Графовый метод динамического декодирования паттернов нейрональной активности

Магистерская диссертация, МАИ, 2026.  
**Автор:** Е.А. Белякова · **Руководитель:** Д.В. Сошников

## О проекте

Метод динамического графового декодирования нейрональной активности на основе Temporal Graph Networks. Применяется к органоидному интеллекту (MEA) и BCI (ЭЭГ, спайки).

**Проблема:** существующие методы используют статические графы и теряют временную динамику связности.

## Данные

- [DANDI:001603](https://dandiarchive.org/dandiset/001603) — MEA-записи органоидов
- [CRCNS pmd-1](https://crcns.org) — спайки моторной коры
- [PhysioNet Motor Imagery](https://physionet.org/content/eegmmidb/1.0.0/) — ЭЭГ, 64 канала

## Стек

Python 3.10+ · PyTorch · PyTorch Geometric Temporal · MNE · SciPy
